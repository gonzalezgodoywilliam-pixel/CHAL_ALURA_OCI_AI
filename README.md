## Asistente Inteligente RAG para Atención de Pacientes

Proyecto de Inteligencia Artificial basado en **RAG (Retrieval Augmented Generation)** diseñado para responder consultas administrativas de pacientes utilizando exclusivamente información contenida en documentos oficiales de la clínica.

El sistema permite consultar información relacionada con:

- Consultas médicas
- Agendamiento y reagendamiento
- Políticas de cancelación
- Convenios y coberturas
- Instrucciones pre y post consulta
- Privacidad de datos del paciente

---

#  Objetivo del proyecto

Desarrollar un asistente virtual capaz de:

- Comprender preguntas realizadas por pacientes.
- Buscar información relevante dentro de documentos clínicos.
- Generar respuestas utilizando Inteligencia Artificial Generativa.
- Mantener trazabilidad indicando las fuentes utilizadas.
- Evitar respuestas inventadas utilizando únicamente información disponible.
